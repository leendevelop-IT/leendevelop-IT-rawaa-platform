# رَوَاء | إعادة تصميم صفحتي «تفاصيل الحديقة» و«التنبؤات وجدولة المتابعة»

تعديل واجهة فقط. لم يتغير أي شيء في الـ Backend أو الـ APIs أو قاعدة البيانات أو خوارزميات التنبؤ أو حسابات الأقمار الصناعية أو منطق العمل. اختبارات الـ Backend الـ 44 ما زالت ناجحة دون تعديل.

## الملفات

| الملف | التغيير |

## صفحة تفاصيل الحديقة

من الأعلى إلى الأسفل:

1. بطاقة الحالة (بدل مربع «الخلاصة بلغة بسيطة» الكبير): شارة الأولوية، الموثوقية، تنبيه «نتيجة مبدئية» عند عدم اعتماد الحدود، ملخص لا يتجاوز سطرين مبني من أرقام القرار، سطر قصير بأسباب التصنيف، شريط «الإجراء المقترح» مع زر الإجراء الفعلي (إسناد مهمة للمقاول، أو رابط المهمة القائمة). وزر «عرض التحليل الكامل».
2. أربع بطاقات متناسقة: NDVI الحالي (مع خط اتجاه مصغّر) · التغير عن المتوقع/المعتاد (سهم ولون) · جودة البيانات (مقياس بعلامتي 60% و80%) · الأولوية (مع موعد الفحص القادم).
3. اتجاه NDVI والتوقع: رسم واحد يفصل بصريًا بين القراءة الفعلية (خط متصل) والتوقع (خط متقطع + نطاق 80%) والمستوى المتوقع موسميًا (خط منقّط)، مع تلميح تفاعلي لكل نقطة، وتحته ثلاث خانات: بعد 7 أيام، بعد 30 يومًا، احتمال استمرار التراجع (أو ثقة التوقع).
4. الحدود والمساحة (بطاقة مختصرة) بجانب الخريطة: المساحة بالهكتار، شريط النباتي/غير النباتي، المصدر، الإصدار، عدد بكسلات Sentinel-2، المحيط، ملاحظة واحدة مختصرة، و«اعتماد الحدود» مع قائمة للإجراءات الثانوية.

اللوحة الجانبية «التحليل الكامل» فيها خمسة تبويبات: الملخص · المؤشرات · التوقع والمتابعة · التشخيص والخطة · الموقع والصيانة.

### أين ذهبت كل معلومة من الصفحة السابقة (لم يُحذف شيء)

| المعلومة | مكانها الآن |
|---|---|
| الخلاصة بلغة بسيطة (العنوان والفقرات) | اللوحة › الملخص |
| الأولوية، الموثوقية، كون النتيجة مبدئية | بطاقة الحالة + بطاقة الأولوية |
| القراءة الحالية والسابقة، التغير، الاتجاه | بطاقتا NDVI والتغير + شرائح «لماذا» + الرسم |
| سبب التصنيف (القائمة الكاملة) وملاحظة الموسم | شرائح مختصرة في البطاقة + اللوحة › الملخص |
| الإجراء المقترح | مختصرًا في البطاقة + كاملًا في اللوحة › الملخص |
| آخر قراءة / خط الأساس / التغير / الحالة العامة (المقياس القديم) مع التلميحات، المصدر، ملاحظة موقع التحقق | اللوحة › الملخص |
| معنى المؤشرات وصيغها، والمؤشرات الطيفية (NDMI, NDRE, SAVI, NDWI, SI، التباين) | اللوحة › المؤشرات |
| التوقع 7/30 يومًا مع نطاقي 80% و95%، الثقة، النموذج، المقارنة بالمرجع، احتمال التراجع أو سبب غيابه، شرح النموذج، مقارنة النماذج، سجل التوقعات | خانات الرسم + اللوحة › التوقع والمتابعة |
| موعد الفحص، حالته، إعادة التقييم، سبب الموعد | بطاقة الأولوية + اللوحة › التوقع والمتابعة |
| التشخيص والأدلة، تنبؤ الأشهر الثلاثة، خطة الصيانة (وزر إنشاء التنبيه) | اللوحة › التشخيص والخطة |
| الحدود: الحالة، المساحة، النباتي، المصدر، الإصدار، البكسلات | بطاقة الحدود |
| تحذيرات الحدود كاملة، الرؤوس، الإحداثيات، آخر مراجعة، سجل الإصدارات | اللوحة › الموقع والصيانة |
| ملخص القراءات (المستخدمة، الغائمة، المستوردة، على حدود سابقة) وسجل القراءات ومصدر كل قراءة | اللوحة › الموقع والصيانة + قائمة «⋯» في رأس الصفحة |
| النباتات (وتحديدها)، الري، تاريخ الزراعة، حالة المصدر | اللوحة › الموقع والصيانة (+ «تحديد النباتات» في القائمة) |
| لوحة Copernicus Browser | اللوحة › الموقع والصيانة + رابط في القائمة |
| برنامج الصيانة المعتمد للشهر | اللوحة › الموقع والصيانة |
| تنبيه «يحتاج تأكيدًا ميدانيًا» | سطر في أسفل الصفحة |
| استيراد CSV، جلب قراءات فضائية، العودة | رأس الصفحة (الثانوي داخل «⋯») |

## صفحة التنبؤات وجدولة المتابعة

- بطاقات إحصائيات أوضح (العدد من الإجمالي، شريط نسبة، وصف الإجراء)، والضغط عليها يرشّح الجدول.
- خمسة أعمدة: الحديقة | الحالة | التوقع | موعد المتابعة | الإجراء.
- شارات صغيرة للحالات، وأسهم للاتجاه (تنعكس في العربية)، والصفوف مرتبة حسب الأولوية ثم الموعد.
- زر «التفاصيل» أو الضغط على الصف يفتح لوحة جانبية فيها القراءة الفعلية والتوقعين مع النطاقات، والرسم، وموثوقية التوقع، وسبب التصنيف، والمتابعة، والحدود، وأزرار: تم الفحص · تعديل الموعد · فتح صفحة الحديقة.
- الإجراءات الثانوية في قائمة «⋯» لكل صف، والتصدير في قائمة «تصدير» واحدة.
- دقة التوقعات الفعلية في بطاقة مختصرة، والشرح في قسم قابل للطي بعنوان «طريقة قراءة هذه الصفحة».

| المعلومة في الجدول السابق | مكانها الآن |
|---|---|
| الحديقة + حالة الحدود | عمود الحديقة |
| الأولوية + الموثوقية | عمود الحالة (الشارة) + اللوحة الجانبية (الموثوقية) |
| القراءة الفعلية، تاريخها، نسبة الصافي | عمود الحالة + اللوحة |
| التوقع 7 و30 يومًا مع النطاقات | عمود التوقع (30 يومًا) + اللوحة (الاثنان مع النطاقات) |
| الثقة، المقارنة بالمرجع، احتمال التراجع | عمود التوقع (الاحتمال) + اللوحة |
| موعد الفحص، حالته، التأخير، إعادة التقييم، السبب | عمود موعد المتابعة + اللوحة |
| التفاصيل، تم الفحص، تعديل | زر التفاصيل + قائمة «⋯» + أزرار اللوحة |

## الاختبار

- 59 فحصًا تفاعليًا آليًا في Chrome (Playwright): الترشيح، قوائم الإجراءات (فتح/إغلاق/Esc/نقرة خارجية)، تصدير CSV، تعديل الموعد، تسجيل الفحص، فتح وإغلاق اللوحة (زر/Esc/نقرة الخلفية)، التبويبات الخمسة دون إعادة بناء الخريطة، النوافذ فوق اللوحة، سجل القراءات ومصدرها، الاستيراد، اعتماد ورفض وتعديل الحدود، إسناد المهمة من بطاقة الحالة، التنقل، تشغيل التحليل، تبديل اللغة والثيم، وصلاحيات المقاول. النتيجة 59/59 دون أخطاء JavaScript.
- لقطات بعرض 1440 و1180 و820 و390 بكسل، عربي/إنجليزي، داكن/فاتح.
- اختبارات الـ Backend: 44/44.

ملاحظة عن اللقطات: التقطت محليًا ببيانات اختبار مُدخلة في قاعدة مؤقتة (ليست قراءات أقمار حقيقية). خلفية الخريطة رمادية لأن بيئة الاختبار لا تصل إلى مزوّد الخرائط Esri؛ في المنصة المنشورة تظهر الخريطة كالمعتاد.

## مراجعة التصميم (نوفمبر 2026)

مراجعة أزالت الأنماط البصرية الجاهزة دون تغيير هوية المنصة أو وظائفها أو منطقها:

- حُذفت العناوين الصغيرة فوق العناوين (مثل «RAWAA / المنصة» و«RAWAA INTELLIGENCE / 01» و«EXPLORE / استكشف»)، والترقيم 01–04 في بطاقات التحليل، وشارة صفحة الدخول ورسمها التوضيحي.
- حُذفت الهالات والتوهج: خلفية صفحة الدخول الشعاعية وشبكة النقاط، والدائرة المتوهجة فوق صورة صفحة التحليل، وتوهج التبويب والقائمة الجانبية النشطة، وخطوط الشبكة في بطاقة الصور الفضائية.
- أُزيل الشريط الملون الجانبي من بطاقة حالة الحديقة ومن الملخص في لوحة التحكم؛ الحالة تظهر في شارة الأولوية وفي أيقونة الملخص.
- أسباب التصنيف تُكتب سطرًا واحدًا بدل مجموعة شارات، وتبقى شارة الأولوية وحدها شارة. في جدول التنبؤات صار «احتمال التراجع» و«تم الفحص» نصًا ملونًا.
- عنوان صفحة التحليل لم يعد يتكرر داخل الصورة الرئيسية، وصار عنوان صفحة «التقارير» قبل لوحة النموذج.
- حد أدنى لحجم الخط (11px للتسميات و12px للنصوص)، وألوان النص الثانوي والشارات في الوضع الفاتح بنسبة تباين 4.5:1 على الأقل بنفس الدرجات اللونية، وحلقة تركيز ظاهرة على أزرار التلميح، وأيقونات مرسومة بدل رموز ✓ و⚠.
